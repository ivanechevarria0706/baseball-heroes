# User Asset Integration — Phase 8R

Source sheets were supplied directly by the user.

Derived assets created in this phase:

- `assets/reference/player_portraits/`
  - 11 transparent roster portraits.
- `assets/reference/card_packs/`
  - 8 transparent pack images.
- `assets/reference/mode_icons/`
  - 12 transparent league/mode graphics prepared for runtime use.
- `assets/reference/celebrations/`
  - 7 cropped comic celebration panels.

The dark-blue sheet background was removed only for assets intended to be used
as sprites. Celebration panels intentionally preserve their full rectangular
art composition.

The custom Hero is intentionally excluded from the fixed roster-art mapping.
