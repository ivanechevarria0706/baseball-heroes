# Baseball Heroes Remake — estado revisado

Recreación personal de **Baseball Heroes (Syntasia)** en ActionScript 3 / AIR.

Esta copia del proyecto fue revisada sobre la versión actual del usuario y conserva las funciones que ya estaban implementadas, corrigiendo errores de ejecución y varios problemas de consistencia.

## Estado actual

### HOME / Lobby
- Estadio como pantalla principal.
- Nivel, XP, energía, monedas y cash.
- Regular Season y Season Goal provisionales.
- PLAY BALL.
- TEAM.
- SCOUT.
- SHOP y BUILD siguen siendo placeholders.

### TEAM / LINEUP
- Roster de jugadores.
- Tarjetas seleccionables.
- Paginación de roster: los jugadores 13–30 ya son accesibles.
- Starting lineup sobre diamante.
- POWER / CONTACT / SPEED / AVG / HR / RBI.
- Acceso a TRAIN y EQUIP.

### TRAINING
- POWER +1.
- CONTACT +1.
- SPEED +1.
- Costos crecientes.
- +25 XP de jugador por entrenamiento.
- Cada 100 XP aumenta el nivel del jugador.
- OVR conserva un valor base y aumenta gradualmente.

### SCOUT
- Bronze Scout: C 5,000.
- Gold Scout: C 20,000.
- Premium Scout: $5.
- Generación aleatoria de jugadores.
- SIGN PLAYER.
- Capacidad máxima actual: 30 jugadores.

### EQUIPMENT
- Bats.
- Gloves.
- Cleats.
- Equipamiento persistente.
- Bonificaciones de POWER / CONTACT / SPEED.
- El panel de EQUIPPED se actualiza inmediatamente al equipar.

### BATTING
- Fastball.
- Curveball.
- Changeup.
- Timing PERFECT / GOOD / FOUL / MISS.
- CONTACT modifica de verdad las ventanas de timing.
- POWER modifica de verdad la velocidad/distancia visual del batazo.
- Camera shake.
- HUD B/S/O.
- ESC vuelve al HOME.

### SAVE / LOAD
Se usa `SharedObject` de AIR.

Se guardan:
- level / xp;
- energy;
- coins;
- cash;
- roster;
- entrenamiento;
- player XP;
- equipment;
- items equipados;
- contador de Scout.

Los datos sobreviven al cierre y reapertura de la aplicación.

## Compilar

Desde la raíz del proyecto:

```powershell
.\build\build.bat
```

El script usa el mismo patrón de compilación que ya funcionó manualmente:

```powershell
amxmlc -source-path="<proyecto>\src" "<proyecto>\src\com\bh\Main.as"
```

y copia el resultado como:

```text
build\BaseballHeroesRemake.swf
```

`compile-config.xml` fue retirado porque ya no era necesario y contenía rutas absolutas antiguas que podían volver a provocar errores del compilador.

---

## Ejecutar

```powershell
.\build\run-air.bat
```

o para compilar y abrir en un solo paso:

```powershell
.\play.bat
```

`play.bat` ya no se detiene en el `pause` intermedio del build.

## Cambios importantes de esta revisión

1. Corregido `EquipmentScreen`:
   - se eliminó `card["itemData"]`, que provocaba Error #1056 porque `Sprite` es una clase sellada;
   - ahora se usa `Dictionary`;
   - el panel BAT / GLOVE / SHOES se refresca inmediatamente;
   - el resumen de atributos efectivos también se refresca;
   - se mantuvo corregido el `return` de `effectiveSummary()`.

2. Mejorado `GameData`:
   - validación de stats y slots;
   - migración de saves viejos;
   - inventario por defecto reparable;
   - save version 2;
   - persistencia del contador de Scout;
   - protección ante roster/save incompletos.

3. Gameplay:
   - CONTACT ensancha las ventanas de timing;
   - POWER afecta el vuelo del batazo;
   - por tanto Training y Equipment ya tienen un efecto directo en batting.

4. Scout:
   - el contador `x / 30` se actualiza inmediatamente después de firmar;
   - el título Premium Scout ya no debería cortarse.

5. UI:
   - textos de Training ajustados para evitar recortes;
   - tarjetas de roster con LV más legible;
   - valores con bonus de Equipment tienen más espacio en TEAM;
   - el roster de TEAM ahora tiene páginas, por lo que los jugadores obtenidos por Scout ya no quedan ocultos después del jugador 12.

6. Build:
   - scripts revisados;
   - comprobaciones de FLEX_HOME / amxmlc / ADL;
   - `play.bat` compila y ejecuta sin pausa intermedia;
   - eliminado el archivo accidental `^`;
   - eliminados del paquete revisado los SWF viejos para evitar ejecutar una compilación obsoleta.
