# First gameplay — THE ROADMAP TO MAJOR

The first gameplay briefly shows a progression screen titled
`THE ROADMAP TO MAJOR` after the early tutorial/mission sequence.

The exact original server objectives and reward table have not been recovered,
so Phase 8W separates verified presentation from reconstructed progression.

## Verified direction

The historical game used five progression levels:

- Rookie
- Single-A
- Double-A
- Triple-A
- Major

The first gameplay presents Roadmap-to-Major as something distinct from the
ordinary Missions screen.

## Phase 8W reconstruction

The remake now has a dedicated persistent Roadmap screen reached from HOME.

Each league displays:
- three account-level objectives;
- progress bars;
- completion state;
- an original-inspired Mystery Box reward;
- a five-league route using the supplied league badge artwork.

Roadmap statistics do not reset between seasons.

Promotion itself remains tied to the existing season system. Completing a
Roadmap stage gives rewards and visual progression but does not bypass the
30-game season / promotion logic.

## Mystery Box

Exact historical Mystery Box contents are not known. 8W therefore uses an
explicitly reconstructed random reward:
- Coins;
- Hero Skill Point;
- premium Cash;
- Energy restoration.

This can be replaced later if exact original reward data is recovered.
