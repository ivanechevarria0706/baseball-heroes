# First gameplay — Build Mode reconstruction

Reference re-inspected:
approximately 9:20–11:30 of
`Facebook - Baseball Heroes - No doy una.mp4`.

## What the original screen shows

Build Mode keeps the stadium visible full-screen. It does not move into a
generic dark editor. A blue dock stays attached to the bottom.

The dock contains:
- SHOP;
- INVENTORY;
- Ticket Sales / gate income;
- a red close button;
- BACK GROUND;
- FIELD;
- SCORE BOARD;
- STAND;
- FENCE;
- FLOOD LIGHT.

The gameplay visibly changes the field, backdrop, scoreboard, stand colors,
advertising/fence and lighting while the tutorial buys upgrades.

## Gate income

The footage explicitly presents:
`Collect +___ Coin / 6 Hours`
and
`Up to +____ Coin / per day`.

Phase 8F therefore changes gate income from the earlier daily approximation
to a six-hour cooldown. The daily number is four collections.

## Local Stadium Growth mission

The tutorial objective is:
1. buy one stadium scenery item;
2. collect gate income one time.

The footage then displays a large `MISSION COMPLETE!` dialog and a Skill
Point reward. Phase 8F reproduces this progression.

## Normal Shop correction

The old remake had more stadium items than could fit in its six visible
catalog cards. Phase 8F adds PREV/NEXT pagination and visible active-tab
labels so the complete STADIUM catalog is accessible.
