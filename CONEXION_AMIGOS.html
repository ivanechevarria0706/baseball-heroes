Descargar el juego 0.6.7

Comparte ese ZIP. Cada amigo debe extraerlo completo y abrir BaseballHeroesRemake.exe. Incluye LEEME.txt; no hace falta instalar AIR, Java, Python ni el SDK.

Dirección para el campo «Servidor» de RIVAL

Esta dirección también abre la versión web. En Windows se usa dentro del campo Servidor de RIVAL.

  1. Abre BaseballHeroesRemake.exe en la carpeta extraída. Crea tu equipo si es tu primera partida y entra a MODES → RIVAL · AMIGOS. El juego usa esta dirección por defecto para sesiones nuevas.
  2. Si tenías iniciada una sesión del servidor local, pulsa SALIR DE CUENTA y pega la dirección de arriba en Servidor.
  3. Para tu primera cuenta, abre tu invitación inicial privada, copia el código y completa usuario, contraseña y nombre visible. Pulsa CREAR CUENTA. El código se utiliza una vez y vence a las 72 horas desde el primer arranque.
  4. Pulsa PUBLICAR MI EQUIPO. Después usa INVITAR para generar un código distinto para cada amigo. Todos deben usar la misma dirección del servidor.
  5. Entra a LIGA PRIVADA, crea la liga y espera a que se inscriban los demás. Confirma el inicio cuando estén todos.

Para jugar en este servidor ya no necesitas abrir SERVIDOR_PRIVADO.bat ni dejar encendida tu computadora para los demás. Las cuentas creadas en las pruebas locales son independientes de las cuentas de internet.
