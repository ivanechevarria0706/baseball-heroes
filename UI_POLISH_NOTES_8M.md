# UI polish notes — 8M

The surviving Baseball Heroes footage uses a consistent visual language:
bright sky/stadium backgrounds, large rounded blue shells, white content
cards, yellow/orange reward/action accents, small chibi player art, compact
resource bars and dense but highly structured information.

Earlier remake phases had many correct systems but mixed several visual styles:
dark developer panels, flat cards, bright original-inspired screens and modern
menu layouts. Phase 8M reduces that inconsistency across four important flow
screens without changing their underlying mechanics.

The Draft and Missions hierarchy follows the interface archaeology already
recorded in `FIRST_GAMEPLAY_INTERFACE_ANALYSIS.md`. Exact raster assets and
server-side formulas are not claimed to be recovered; all artwork remains an
original vector reconstruction inspired by the surviving footage.
