Entrar y jugar

  1. Abre el enlace y usa tu cuenta del servidor de internet de RIVAL. Las cuentas del antiguo servidor local son independientes.
  2. Si no tienes cuenta, elige Crear cuenta y completa usuario, contraseña y nombre visible. No necesitas código de invitación.
  3. Comparte el enlace de la página con tus amigos. Dentro del juego, entra a MODES → RIVAL y publica tu alineación para que puedan retarte. El botón ENLACE muestra la dirección para compartir.
  4. En LIGA PRIVADA, crea la liga y espera a que todos se inscriban antes de iniciarla. Cada local juega a su horario contra la simulación del equipo rival.

Empezar desde nivel 1

Las cuentas nuevas empiezan en la liga ROOKIE y en el primer partido de la temporada. El equipo inicial no tiene resultados anteriores ni equipamiento avanzado.

Si ya tienes una carrera avanzada y quieres comenzar desde cero, pulsa NUEVA CARRERA. Se descargará un respaldo antes de reiniciar. Se conservan el nombre y aspecto de tu héroe, tu cuenta y las ligas y retos con tus amigos. Después puedes publicar otra vez tu nueva alineación desde RIVAL.

Llevar tu partida de Windows

Si prefieres conservar el avance anterior, tu partida se exportó a Partida_para_web.json. El archivo original de Windows se conserva.

  1. Guarda ese archivo en tu computadora.
  2. Inicia sesión en la página y pulsa IMPORTAR PARTIDA en la barra superior.
  3. Selecciona el JSON y confirma el equipo. La página descargará un respaldo del progreso anterior antes de importarlo.
  4. Espera a ver Guardado en la nube ✓. A partir de ahí, continúa desde la web con esa cuenta.

Importar recupera el avance del archivo; para empezar desde nivel 1 utiliza NUEVA CARRERA. Este archivo contiene tu progreso personal: no lo compartas con tus amigos. La edición Windows y la partida de la web no se sincronizan entre sí. La exportación personal no está incluida en el despliegue.

Guardado y actualizaciones

El progreso se guarda por cuenta. Puedes entrar desde otra computadora para recuperar el último guardado. Si hay un corte de conexión, la página conserva los cambios pendientes en ese navegador y permite reintentarlos. Espera la confirmación antes de cerrar.

Usa una sola pestaña para avanzar tu partida. Si dos pestañas intentan guardar versiones distintas, el juego se pausa y ofrece descargar la copia local para evitar sobrescribir el progreso.

Cuando publiquemos una mejora, aparecerá Guardar y actualizar. Puedes terminar lo que estés haciendo antes de pulsarlo. El juego no se recarga automáticamente en medio del partido.

La temporada se guarda en sus puntos habituales; no permite reanudar cualquier lanzamiento de un partido local. Los retos de RIVAL sí guardan cada turno en el servidor.

Se conservan los sistemas y recursos del remake mediante Ruffle autoalojado. La mejora de esta entrega es el acceso web; acercar el arte y las animaciones al original sigue siendo el siguiente trabajo.
