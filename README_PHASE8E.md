# Baseball Heroes Remake — Phase 8E
## Historical Lineup Reconstruction

This phase reconstructs the interface shown around 12:50–13:50 of the first
gameplay video.

- LINE UP / SUBSTITUTE two-column layout;
- original-inspired 1st Regular Season header and resource bar;
- 1–9 player rows with portraits, AVG and ability meters;
- ALL / SPECIAL substitute filters;
- click-to-swap players;
- drag-and-drop substitutes directly onto lineup slots;
- historical Special Batter slot boxes;
- SPECIAL BATTER SLOT popup with HERO/ELITE/RARE/NORM probabilities;
- BATTER SHOP navigation from the lineup;
- TRADE & ENHANCE screen;
- persistent Power/Contact/Luck enhancements;
- offline player trade/release for Coins;
- team-vs-rival comparison card;
- HOME / AUTO SORT / PLAY bottom controls;
- existing Phase 8D/8C progression, clean audio, batting and simulation preserved.
